How to add a lecture note

Drop a new .md file into source/file_lecture/ with front matter like this:

It will automatically show up in the full list at /file_lecture/ (linked as
“All notes” from the Lecture and Notes section on the home page), sorted by
date (newest first) – no need to edit any index or config file. Subfolders
under source/file_lecture/ work too; everything underneath is picked up.
